Base de données

Une IA conçoit les tables, écrit l'app et la branche dessus. Sans réglage, les données restent dans le navigateur (en local comme une fois déployé). Avec Supabase, l'app locale et l'app déployée partagent la même base. L'aperçu utilise une base en mémoire.
Chaque génération est réalisée par Claude et utilise ton quota. La plateforme choisit le modèle exact de chaque niveau ; le niveau réellement utilisé s'affiche après la génération.
