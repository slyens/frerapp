# App Forge

Page autonome qui génère des projets web multi-fichiers avec Claude.

- `index.html` : toute l'application (HTML, CSS et JS inline).
- La génération repose sur la capacité « sample » des artifacts Claude : elle ne fonctionne donc que publiée sur claude.ai,
  pas en ouvrant le fichier directement dans un navigateur.
